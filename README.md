# 军棋人机对战 (Junqi / Chinese Military Chess)

> 经典军棋终端游戏，支持人机对战。

## 在线试玩

- **直接在线玩**：[点击这里开始游戏](https://htmlpreview.github.io/?https://github.com/3q110/junqi/blob/main/index.html)
- **本地运行**：下载 `index.html` 后双击打开，无需服务器

## 游戏规则

### 棋盘
- 棋盘为 11×7 网格（不含界河），双方各占一侧
- 铁路线：第 2、5、9 行为横向铁路，左右边界第 0/6 列第 1-9 行为纵向铁路
- 己方底线两侧为两个"大本营"（军旗所在，敌方军旗被吃前不可进入空大本营，但可吃掉军旗获胜）

### 棋子（每方 24 枚）

| 棋子 | 数量 | 说明 |
|------|------|------|
| 司令 | 1 | 最大军衔，可吃除炸弹、地雷外所有棋子 |
| 军长 | 1 | |
| 师长 | 1 | |
| 旅长 | 1 | |
| 团长 | 1 | |
| 营长 | 1 | |
| 连长 | 1 | |
| 排长 | 1 | |
| 工兵 | 1 | 可挖地雷，可修铁路 |
| 炸弹 | 3 | 与任何棋子同归于尽（含司令） |
| 地雷 | 3 | 只能放在底线，不可移动，炸死除工兵外所有棋子 |
| 军旗 | 1 | 被吃掉则判负，不可移动 |

### 胜负判定
- 吃掉对方军旗 → 胜
- 对方无棋可走 → 胜
- 己方军旗被吃 → 负

### 移动规则
- 普通棋子：每次走一步（上下左右）
- 铁路线上的棋子：可沿铁路走任意格
- 工兵：可在铁路线上拐弯行走（BFS 全铁路网）
- 行营（安全区）：行营内的棋子不能被攻击
- 无棋可走判负：轮到某方时无任何合法移动则判负；双方均无棋可走判和棋
- 步数上限：超过 500 步（每方 250 步）未分胜负判和棋，防止无限僵持

### 战斗规则
- 高军衔吃低军衔
- 同军衔相撞 → 同归于尽
- 炸弹 → 与任何棋子同归于尽（军旗除外）
- 地雷 → 不可移动，只能被工兵挖或炸弹炸
- 工兵 → 可挖地雷（工兵存活，地雷被毁）
- 军旗 → 不可移动，被吃即输

## 安装与运行

```bash
# 需要 Python 3.9+
pip install -e .

# 启动游戏（可选择难度 easy / medium / hard）
junqi
```

## 项目结构

```
junqi/
├── jiqi/            # 游戏核心
│   ├── piece.py     # 棋子定义
│   ├── board.py     # 棋盘逻辑
│   ├── rules.py     # 战斗规则
│   ├── ai.py        # AI 对手
│   ├── player.py    # 玩家操作
│   ├── ui.py        # 终端界面
│   └── game.py      # 游戏主循环
├── tests/           # 单元测试 (50 tests)
├── index.html       # 浏览器在线版
└── pyproject.toml
```

python3 -m unittest discover -s tests -v
